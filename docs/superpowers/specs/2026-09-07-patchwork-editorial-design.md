# PatchworkMD website: approved visual direction
Date: 2026-09-07

## Intent and approval
Austin approved the film/editorial concept board in this task, then requested clean product presentation, logos, demos, distinctive animation and consistent maker credits across apps. This document turns that approval into an implementation scope. Preserve the existing Sites project and patchworkmd.dev domain.

## Direction
Use warm paper, charcoal typography, restrained burnt-orange accents, fine editorial rules and analog photographic texture. Combine historical technology annual-report composition with contemporary digital clarity. The existing X artwork supplies character: CRT equipment, a camera and an inhabited creative workspace. Avoid turning the page into a fake operating system.

The recommended balance is editorial structure with film imagery. An all-dark CRT environment would overwhelm product content. A heavy scrapbook would weaken clarity. Neither replaces the approved direction.

## Homepage
A compact masthead contains the new original PatchworkMD mark, projects navigation and contact. A left-aligned cover statement introduces independent software. Follow with a featured available product and a clean selected-work index. Each product has its real logo, concise purpose, honest availability and a useful destination. Feature only verified public releases; in-development products remain clearly labeled. Do not invent download buttons, launch dates, usage counts or testimonials.

Use existing genuine screenshots and demos from product owners. A demo may be an accessible video with poster and controls, or a small real interactive example. No autoplay audio. Never present a fabricated application screenshot as product evidence. Product titles, controls and descriptions remain live HTML, not baked into a board image.

## Logo and motion
Refine an original compact viewfinder-inspired mark and wordmark; test at favicon, header and footer sizes. The four-green-tile draft is superseded by the approved editorial concept. Keep final lettering PatchworkMD and domain patchworkmd.dev.

Use short entrance choreography, subtle image reveals and responsive hover/focus feedback. Camera-inspired motion means framing and focus, not flashing white shutter effects. Avoid perpetual distracting loops. Respect reduced motion with a complete static presentation. Animate transform and opacity; do not move layout dimensions. Keep primary navigation usable before motion finishes.

## Product pages and maker credit
Reuse the typography, spacing and navigation language across portfolio product pages. Preserve product-specific logos and imagery. LocalModelMatch is already live in the portfolio; preserve the /localmodelfit to /localmodelmatch redirect.

Use Made by PatchworkMD linked to https://patchworkmd.dev as the consistent maker credit. Websites place it in the footer. Native apps place it in About or Settings. Keep it quiet and accessible. Each product owner implements the credit in its existing source and release cycle; this website task does not silently ship app binaries.

## Technical scope
Keep the existing vinext/React/Sites stack. Reuse existing content and product routes. Consolidate conflicting CSS while preserving functional states and unrelated drafts. Add only the smallest shared brand component needed. Use existing dependencies or CSS before adding a library. Preserve hello@patchworkmd.dev and all approved contact behavior.

## Verification and release
Check desktop and narrow mobile layouts, no horizontal overflow, keyboard navigation, contrast, reduced motion, links, actual media playback and clear release states. Build the exact release source, exclude unpublished privacy drafts, package with the existing Sites helper, push exact source and deploy a saved version. Verify the public homepage and featured product flow. Retain v7 as rollback.
